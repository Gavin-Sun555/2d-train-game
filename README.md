# 2D Train Game

俯视角 2D 电车 / 轻轨 / 地铁模拟，**Go + [Ebitengine](https://ebitengine.org/)**。

## 开始菜单与三个页面（v0.5）

进入游戏先选地图：**01 网格新城**（生成的规整城市）或 **02 西雅图 · 市中心与南湖联合区**（真实地图）。每张卡片可以「开始建设」（空白）或「载入示例线路」。游戏中按 `Esc` 返回菜单，各地图的进度保留。

和 2d-bus-game 一样，游戏分成三个页面，`Tab` / `Shift+Tab` 或点击顶部标签切换：

| 页面 | 做什么 | 操作 |
| :--- | :--- | :--- |
| **建设** | 铺轨、设站、拆除 | `1` 轨道 `2` 车站 `3` 拆除；`M` 轨道形式；`L` 层级（高架 / 地下预留） |
| **规划** | 建立和管理线路，地图上按线路颜色画出每条线的走向 | 依次点击车站、回车建线；右键撤销一站；点击左上线路选中后，右上面板配置**电车数量**（`+`/`-`，每线最多 12 辆）和**列车编组**（`[` `]`，2–5 节、每节 6 m），并显示估算的周转时间和发车间隔；`Delete` 删除 |
| **运行** | 汽车和电车开始运营 | 点击电车或左上线路**跟踪**这辆电车（镜头跟随，左下显示线路、车速和下一站）；`F` 切换下一辆；拖动或 `WASD` 退出跟踪；空格暂停，`+`/`-` 倍速，`C` 汽车数量 |

建设和规划时运营暂停、不显示车辆；改动后进入「运行」时运营重新开始。

命令行：`-map grid|seattle` 跳过菜单，`-demo` 载入示例，`-page build|plan|run`，`-follow` 跟踪第一辆电车，`-fleet 辆,节` 设定所有线路的车辆，`-line N` 在规划页选中第 N 条线，`-warp 秒`、`-cam x,y,zoom`、`-shot 文件` 用于截图。

## 地图：西雅图市中心 + South Lake Union（v0.4）

第二张地图是真实的西雅图 Downtown 与 SLU（约 1.35 × 2.75 km，南到 Madison St，北到联合湖南岸，西到 Elliott Bay，东到 Fairview Ave），数据来自 OpenStreetMap：

- **道路**：真实路网、路名、车道数和单行道；路口按真实位置生成，相距很近的路口与双幅路合并，地图边缘截断的单行道被剪掉。
- **建筑**：1061 栋真实建筑轮廓（含多边形关系描述的大楼），按楼高（`height` / `building:levels`）投下阴影；屋顶按高低楼配色并带设备。
- **地面**：Elliott Bay、联合湖、公园、草地、停车场和 OSM 中登记的 1013 棵行道树。
- **示例（`-demo`）**：沿 OSM 中真实的 SLU Streetcar 轨道铺轨（Westlake Ave → Lake Union Park → Terry Ave → Fairview & Campus Dr），8 个真实站名。
- **单行道上的电车**：单行道只铺一条顺车流方向的轨道；单行道上的车站只在该方向停靠，线路回程自动跳过（停站顺序由 `LineCycle` 按当前轨道算出）。单行道尽头不能折返。

地图数据 © OpenStreetMap contributors，依 [ODbL](https://www.openstreetmap.org/copyright) 授权；游戏内右下角有署名（透明底小字）。导入工具 `cmd/osmimport` 把 OSM XML（`api.openstreetmap.org/api/0.6/map?bbox=…` 分块下载）转换为 `mapdata/seattle.json.gz`。

## 玩法（v0.3：双线 / 单线电车、渡线折返）

城市有三级道路和汽车交通。电车轨道铺在道路上，`M` 在三种形式之间切换：

- **双线 · 独立路权**：每个方向最内侧车道各铺一条轨道，只给电车用，汽车车道减少一条。支路设成独立路权后就变成电车专用街。
- **双线 · 混行**：轨道嵌在最内侧车道里，汽车和电车共用、互相跟车；电车停站时后面的汽车也要等。汽车寻路时会尽量避开混行车道。
- **单线 · 往返（拉风箱）**：道路中央加一条电车专用轨道（道路相应加宽），两个方向共用。相连的单线组成一个区间，**同一时间只放一辆电车进入**（路签式），电车在线路两端换端折返。

**终点折返**：双线的尽头自动生成一组**渡线道岔**（终点路段太短放不下时，自动改为单线尽头：电车在路口经道岔进入单线，到头换端）。电车从进站轨道经渡线换到对面轨道，逆向驶入尽头的折返线，停车换端后按正常方向开出（站前折返）。逆向进入折返线前，必须确认线上没有汽车或其他电车；电车在折返线上时，汽车也不会驶入。单线尽头则直接停车换端。

| 键 | 工具 / 操作 |
| :--- | :--- |
| `1` 轨道 | 点击一条道路给它铺轨；或点击路口 → 另一个路口，沿最短道路铺轨（可连续点）。`M` 切换轨道形式，右键结束。 |
| `2` 车站 | 点击有轨道的道路放置车站（两个方向各一个站台，离路口至少 40 m）。 |
| `3` 线路 | 依次点击车站，`Enter` 建线（默认一辆 3 节电车往返，可在规划页配置）；右键撤销，`Backspace` 删除最新线路。 |
| `4` 拆除 | 点击道路拆除其轨道（连同车站）。 |
| `C` | 汽车数量 0 / 200 / 400 / 600 |
| `Tab` | 建造层级（高架 / 地下预留给轻轨和地铁，暂未开放） |
| 按下拖动（触控板按压或鼠标左 / 中键）、`WASD` / 方向键 | 平移地图（移动不到 5 像素算点击，松开时生效） |
| 双指捏合（Mac 触控板）、鼠标滚轮 | 缩放；触控板双指滑动不会触发缩放 |
| `Space`、`+`/`-` | 暂停、倍速 |

## 道路与交通

| 等级 | 每方向车道 | 限速 | 备注 |
| :--- | :--- | :--- | :--- |
| 支路 street | 1 | 40 km/h | 每 8 格一条 |
| 主干道 avenue | 2 | 50 km/h | 每 24 格一条，两格宽 |
| 大道 boulevard | 3 | 60 km/h | 中央 3 m 绿化分隔带，岛式站台设在分隔带上 |

- **车道图**：每条道路按等级生成各方向车道（右侧通行），路口内生成贝塞尔连接线：外侧车道右转、内侧车道左转、按外侧对齐直行；转角和 T 字口有兜底规则，保证没有死路车道。电车连接线只在两条有轨道的道路之间生成。
- **信号灯**：三岔以上、且有主干道 / 大道或电车经过的路口设两相位定时信号（东西 / 南北；绿 24 s、黄 3 s、全红 2 s，各路口错开）；其余路口先到先行。
- **驾驶模型**：汽车和电车都用 IDM（智能驾驶模型）跟车，弯道和限速提前减速。
- **路口通行权**：只有排在停止线最前面的车才能申请；需要信号允许、所有冲突连接线（路径交叉或汇入同一车道）无人占用、出口车道有足够空间。拿到后直到车尾离开路口才释放，所以冲突路径永远不会同时有车，也不会把车堵在路口里。
- **汽车**：随机起终点按车道图寻路，到达后消失并补充新车；拥堵车道不生成新车；在车道上停滞超过 4 分钟的汽车会被清理（不会从路口里移除）。
- **电车**：在站台精确停车、停站 20 s，按线路顺序往返；在终点经渡线或单线尽头停车换端（约 8 s）。
- **轨道区间**：单线区间和折返线是"区间"，按行驶方向记账：单线一次一辆电车；折返线逆向进入要求区间为空，正向（含汽车）只要求没有逆向车辆。区间与路口通行权一起在停止线前申请，不会把车堵在路口里。
- **多车运营**：每条线的电车按「周转时间 ÷ 车数」的间隔从首站依次上线（首站轨道空出、区间允许时才放车）。全线都是同一段单线、没有会车点的线路只能跑 1 辆。站台和折返线按最长的 5 节（30 m）编组修建，较短的列车停在站台中央。

## 结构

| 目录 | 作用 |
| :--- | :--- |
| `mapdata` | 真实地图数据（OSM 导入，内嵌压缩 JSON）。 |
| `cmd/osmimport` | OSM XML → `mapdata` 导入工具：投影、裁剪、海岸线闭合成水面。 |
| `city` | 生成网格城市的地块（道路走廊、桥、水、公园）与建筑用地（写字楼、商铺、住宅、院落、广场、公园），按种子确定性生成。 |
| `street` | 地面道路网（生成网格或 `FromMap` 真实路网，支持单行道和不对称车道）：道路等级、路口、车道图、信号灯，以及路面上的电车轨道、车站和线路。 |
| `traffic` | 汽车与电车的交通模拟（IDM、信号、路口通行权），固定步长、确定性执行。 |
| `build` + `rail/sim` | 独立路基轨道与闭塞信号模拟，**预留给高架轻轨和地铁**。 |
| `game` | Ebitengine 表现层：镜头、输入、工具；每帧按屏幕分辨率矢量绘制（批量三角形 + 视野裁剪），风格与 2d-bus-game 一致。 |
| `internal/textui` | 中文字体渲染（与 2d-bus-game 相同）。 |
| `internal/platforminput` | macOS 触控板捏合手势（purego 挂接原生事件），与 2d-bus-game 相同。 |
| `main.go` / `shot.go` | 入口；`-demo` 示例线网，`-warp` 快进，`-cam x,y,zoom` 镜头，`-shot` 截图。 |

所有模拟包都不引用 ebiten，可以 headless 测试与回放。

## 为地铁与高架轻轨预留的设计

- **两套运行方式**：地面电车像汽车一样"看得见就开"，在 `traffic` 里与汽车一起模拟；高架和地下线路用 `rail/sim` 的闭塞信号系统。以后用坡道 / 隧道口把两者连起来。
- **层级 `sim.Level`**：`Ground` / `Elevated` / `Underground`。节点和轨道都带层级，同层才会自动连接、生成路口；不同层的轨道交叉互不影响。
- **层级规则 `build.Rules`**：每层可通行的地块不同（高架可跨水，地下任意），`Buildable` 控制是否开放。
- **运营模式 `build.Mode`**：`Tram` / `LightRail` / `Metro`，各自有所属层级和车辆参数。

## 闭塞信号模拟（`rail/sim`，供轻轨 / 地铁使用）

- 节点 + 直线边，默认每条边一个闭塞分区；同一路口相连的边合并为一个闭塞。
- 按"制动距离 + 50 m"向前预留区间，被占用时停在红灯前；车尾驶出后释放。
- 寻路限制转角 ≤ 90°、禁止中途折返；终点站自动换端折返；速度曲线 `v = min(Vmax, √(2·d·s))`，精确停车。

## 使用

```bash
make run              # 启动（西雅图）
make demo             # 带示例电车线网启动
make test             # headless 测试（安全不变量定期检查）
make shot WARP=300    # 示例线网快进 300 秒后截图到 shot.png
```

## 已知限制 / 下一步

- 汽车不会中途变道，在路段起点就选好车道；左转为许可型，与对向直行先到先行。
- 编辑轨道后交通会重置；尚无撤销、存档、时刻表、乘客与经济。
- 双线与双线相交的路口会自动生成全部方向的电车连接线，暂时不能手动取舍。
- 单线与双线只能在路口处转换，单线区间中间还不能设会车线。
