# 2D Train Game

俯视角 2D 电车 / 轻轨 / 地铁模拟，**Go + [Ebitengine](https://ebitengine.org/)**。

## 结构

| 目录 | 作用 |
| :--- | :--- |
| `rail/sim` | 纯模拟核心，**禁止引用 ebiten**。固定步长 `DT = 1/60 s`，确定性执行，可 headless 测试与回放。 |
| `game` | Ebitengine 表现层，只读取 `sim` 的状态进行绘制与输入处理。 |
| `main.go` / `shot.go` | 入口；`-shot` 截图模式用于自动化检查画面。 |

## 模拟模型（v0）

- **轨道网络**：节点 + 直线边；每条边同时就是一个**闭塞分区**。
- **列车位置**：`trail`（从车尾到前方已占/已预留的区间）+ `head`（车头距 `trail[0]` 起点的距离），不使用物理引擎。
- **闭塞信号**：列车按"制动距离 + 50 m"向前预留区间，区间被其他列车占用时停在红灯前；车尾完全驶出后释放区间。车站出站信号在停站结束前保持红灯。
- **速度曲线**：`v = min(Vmax, √(2·d·s))`，保证在移动授权终点前停稳；车头精确停在站台端。
- **折返**：下一段线路从当前所在边反向开始时，自动在终点站换端折返。

## 场景

1. **Shuttle**：单线三闭塞，一列车往返东西两站。
2. **Loop**：单向环线六闭塞、两站、三列车；T2 开局紧跟 T3，必须在红灯前等待。

## 使用

```bash
make run SCENARIO=2   # 启动
make test             # headless 测试（安全不变量每 tick 检查）
make shot WARP=300    # 快进 300 秒后截图到 shot.png
```

按键：`1`/`2` 切换场景，`Space` 暂停，`+`/`-` 倍速（1×–32×），`R` 重置。

## 已知限制 / 下一步

- 还没有道岔与进路联锁；单线上的对向列车会互相锁死（需要进路级预留或交会站）。
- 区间 = 边，尚不支持一条长边切成多个闭塞，或移动闭塞（CBTC）。
- HUD 用的是 ebitenutil 调试字体，只能显示英文；中文需要接入字体（可复用 bus game 的 `textui`）。
- 尚无存档、时刻表、乘客。
