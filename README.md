# 2D Train Game (v0.0.1)

俯视角 2D 有轨电车 / 轻轨模拟游戏，使用 **Go + [Ebitengine](https://ebitengine.org/)** 构建。

支持在生成的规整网格城市与真实比例的西雅图城区中铺设**街道轨道、空地独立轨道、跨河跨路高架桥与地下隧道**，从 **31 款中外现代及 1950 年代经典老电车**中选配车队，在与最多 3000 辆 AI 汽车共用的多相位信号路网中组织客运运营。

---

## v0.0.1 功能汇总

### 1. 双地图与五层城市空间
- **01 网格新城（Grid City）**：按随机种子确定性生成的城市街区，包含三级道路（支路 / 主干道 / 中央分隔带大道）、蜿蜒河流与桥梁、街心公园、广场、写字楼、商铺、院落与住宅。
- **02 西雅图 · 中心城区（Seattle）**：基于 OpenStreetMap 真实数据导入的 `7354 × 5860 m`（约 `43 km²`）城区，覆盖 Elliott Bay、联合湖、Downtown、South Lake Union、Capitol Hill 至华盛顿湖西岸：
  - **真实路网**：3000+ 条真实命名街道、单行道、不对称车道与路口车道渐变收窄；I-5、SR 99、SR 520 高速公路与匝道、跨线桥、地下隧道独立分层渲染。
  - **建筑与地标**：13,900+ 栋带真实高度与统一日照阴影的建筑轮廓、1000+ 棵行道树、水面与大型公园，以及太空针塔、派克市场、国王街车站等 **42 处可自定义改名的城市地标**。
- **五层空间视图（`L`）**：超高层（`+2`）、**高架层（`+1`）**、**地面层（`0`）**、**地下层（`-1`）**、深地下层（`-2`），其中地面、高架、地下三层均开放有轨电车建设与设站。

### 2. 全地形与立体轨道建设
- **三种轨道形式（`M`）**：
  - **双线 · 独立路权**：占用内侧专用车道或独立路基，仅供有轨电车通行。
  - **双线 · 混行**：轨道嵌入道路内侧车道，与社会车辆混行跟车。
  - **单线 · 往返**：单条双向共用轨道，相连单线自动组成路签闭塞区间，同一时刻仅允许一列电车进入。
- **街道铺轨与空地直接建轨**：
  - 在地面街道上单击即可铺轨，或连续点击路口沿最短街道自动铺设。
  - 支持脱离现有道路，直接在**公园、河岸或街区空地**点选「起点 → 终点」建造碎石道床独立轨道；平交横穿汽车道路时自动切分街道、铺设平交道口并生成信号灯。
- **高架段（`+1`）、地下隧道（`-1`）与出入坡道**：
  - 在地面选定起点后按 `L` 切换至高架层或地下层点击终点，即可建造 `0 <-> +1` 高架引桥或 `0 <-> -1` U 型隧道出入口（坡道限速 `50 km/h`）。
  - **高架桥**：带混凝土桥墩、护栏与地面投影，可自由跨越河流与地面街道（自动避让高层建筑），支持建设 `[高架]` 车站。
  - **地下隧道**：可自由下穿河流、建筑群与地面高速，支持建设 `[地下]` 车站；跟随地下运行电车时自动开启透视剖面视图。
  - **道路冲突拦截与信号保护**：严禁出入坡道中途横穿地面街道或直接压在汽车车行道内；电车从路口进出坡道或平交穿过街道时，自动配置多相位受保护专用电车信号灯与汽车红绿灯。
- **车站、交叉渡线与道路改造**：
  - **站台**：支持 `1–8 节`（每节 `6 m`，最长 `48 m`）站台长度调节（`[ ]`），规划页可点击站名或按 `N` 修改站名。
  - **交叉渡线**：在平坦双线轨道上建设 `18 m` 交叉渡线，支持站前折返、站后折返、中途折返及逆向区间预留。
  - **道路工具（`5`）**：支持新建街道、拆除街道（自动清理断头路）及调整单行 `1/2` 车道或双向 `1+1 / 2+2 / 3+3` 车道。

### 3. 31 款现代与经典电车库 + 45× 高清追踪模式
- **车型分类筛选与独立动力学**：规划页与线路管理窗口提供车型选择器（支持 **`全部 / 现代电车 / 经典老车(<=1950)`** 筛选及滚轮浏览），每款车型具备独立的加速度、减速度、车宽与最高设计时速（`40–100 km/h`）：
  - **中国现代有轨电车（5 款）**：中车株机海珠超级电容电车、中车浦镇苏州有轨电车、中车四方氢能源电车、中车大连北京西郊线电车、中车长客武汉光谷无网电车。
  - **欧洲现代电车（6 款）**：Alstom Citadis 305、Siemens Avenio、Stadler Variobahn、Bombardier Flexity Outlook、Škoda ForCity Alfa、Stadler Tango。
  - **北美现代轻轨/街车（5 款）**：Siemens S700、Bombardier Flexity Freedom、Brookville Liberty NXT、Kinkisharyo LF、Kinkisharyo P3010。
  - **日本现代路面电车（5 款）**：宇都宫芳贺 HU300 Lightline、广电 5200 型 Green Mover APEX、富山地铁 9000 型 Centram、熊本市电 0800 型 COCORO、札幌市电 A1200 型 Polaris。
  - **1950 年代及以前经典老电车（10 款）**：PCC 流线型电车 (1936)、Birney 安全型单节电车 (1916)、Peter Witt 米兰老电车 (1928)、新奥尔良 Perley Thomas 电车 (1923)、里斯本 Remodelado 老电车 (1930)、维也纳 M 型老电车 (1928)、伦敦 Feltham 老电车 (1931)、柏林 T24 老电车 (1924)、大连 3000 型老电车 (1935)、广岛电铁 650 型老电车 (1942)。
- **45× 超高倍跟随细节**：跟随模式下镜头可放大至 `45×`（普通地图模式最高 `10×`），矢量呈现前风挡雨刮、后视镜、司机操控台、终点显示牌、滑移车门与亮起踏步、车顶空调/超级电容/氢能舱与受电弓；经典老电车拥有专属排障器、单颗黄铜圆头大灯、米色窗框饰带、天窗高顶/拱顶与集电杆。

### 4. 精细化线路运营与客流模拟
- **实时生效的运营调优**：
  - **运营最高限速**：可按线路设定运营限速（自动受所选车型本身支持的最高速度约束），调整后在运行中实时生效。
  - **平滑动态定员**：调整每节车厢载客定员（`10–200 人/节`）无需重置运营；若车上现有乘客超出新设定的定员，列车靠站自动执行**「只下不上」**，待载客降至新定员以下后自动恢复正常上客。
  - **停站与上下客参数**：可按线路实时调整中途最少停站时间（默认 `20 s`）、终点换端最少停站时间（默认 `60 s`）、每人上/下车耗时及每节并发车门数。
- **真实车门状态机与按方向乘车**：
  - 到站停稳后依次执行：开门（`2 s`）→ 先下客后上客（停站期间新到站台的同向乘客可继续登车）→ 关门提示音与关门（`3 s`）→ 发车。
  - 自动识别环线、往返线及回字形折返点，乘客仅登乘在下一折返点前能到达目的地的列车。
- **线路管理面板（`T`）**：实时统计各线路单程长度、完成单程数、平均耗时、含停站运营均速、实际发车间隔、累计送达客流、人公里满载率、各站候车柱状图及单车追踪状态。

### 5. AI 道路交通、信号灯与实时合成音效
- **道路交通模拟**：基于 IDM（智能驾驶模型）跟车与双车轴平滑转向，支持 `200–3000` 辆均匀分布的 AI 汽车与 `×1–×16` 倍速运行；路口通行权对所有交叉及合流连接线严格互斥，杜绝路口锁死与碰撞。
- **实时程序化音效与报站（`V`）**：
  - 无需外部音频素材，由 `internal/sound` 实时合成 **4 种牵引电机/老电车齿轮声**、**4 种路口铜钟/叮叮电铃声**、**4 种气动/塞拉/折叠车门声**，支持按屏幕远近与左右位置立体声混音。
  - 跟踪电车时提供中英文双语、4 种音色的到站预告与出站语音报站。
- **全状态多槽位存档与双语界面**：
  - 支持简体中文 / English 切换（自动识别系统语言并持久化至 `settings.json`）。
  - 每张地图提供「当前进度」+ **10 个手动存档位（`F5` / `F9`）** + **5 个轮换自动存档**，完整保存道路与跨层轨道编辑、车辆位置、车门与上下客进度、站台候车队列及运营统计。

## 操作指南

游戏分为 **建设 / 规划 / 运行** 三个页面（`Tab` / `Shift+Tab` 或点击顶部栏切换，`Esc` 返回主菜单并自动保存）：

| 页面 | 按键 / 操作 | 说明 |
| :--- | :--- | :--- |
| **通用** | 鼠标拖动 / `WASD` / 方向键 | 平移地图（运行页拖动会自动退出电车跟随） |
| **通用** | 鼠标滚轮 / 触控板双指捏合 | 缩放视图（普通最高 `10×`，跟随电车时最高 `45×`） |
| **通用** | `T` / `V` / `F5` / `F9` | 线路管理窗口 / 声音设置面板 / 保存存档 / 读取存档 |
| **建设** | `1` 轨道 | 单击街道铺轨；或在空地/路口依次点击起点 → 终点建独立轨道（右键结束） |
| **建设** | `L` / `M` | 切换建设与查看层级（地面 / 高架 / 地下）/ 切换轨道形式（独立 / 混行 / 单线） |
| **建设** | `2` 车站 · `[` `]` | 在街道轨道、空地轨道、高架桥或地下隧道设站，`[ ]` 调节 `1–8 节`站台长度 |
| **建设** | `3` 渡线 · `4` 拆除 · `5` 道路 | 在双线轨道建交叉渡线 / 拆除渡线或轨道段 / 新建、拆除汽车道路与改车道 |
| **规划** | 点击车站 + `Enter` | 按顺序点选各层车站后回车建线；右键或 `Backspace` 撤销一站 |
| **规划** | 面板控制 / `N` | 配置车型、车辆数（`+/-`）、编组（`[ ]`）、每节定员（`< >`）、运营限速与停站时间；`N` 车站改名 |
| **运行** | 点击电车 / `F` | 开始跟随该电车（放大查看高清车身与地下剖面）；`F` 切换下一辆 |
| **运行** | `Space` · `+/-` · `C` · `P` | 暂停与继续 / 切换 `×1–×16` 倍速 / 调整 AI 汽车数量 / 调整乘客生成速度 |

## 编译与运行

环境要求：**Go 1.27+**（macOS / Linux / Windows，依赖 Ebitengine 图形环境）。

```bash
# 编译可执行文件
make build

# 启动游戏（进入地图与语言选择主菜单）
make run

# 直接载入西雅图示例电车线网启动
make demo

# 运行全部静态检查与无头模拟/UI单元测试
make test

# 快进模拟并输出截图
make shot WARP=120
```

常用命令行参数：

```text
-map grid|seattle    直接打开指定地图
-demo                载入内置示例线网（不覆盖玩家存档）
-page build|plan|run 启动后直接进入指定页面
-lang zh|en          指定界面语言（简体中文 / English）
-model <key>         将示例线路统一设为指定电车车型（如 crrc-suzhou, pcc-1936, siemens-s700）
-fleet <辆,节>       统一设定每条线路的配车数与编组节数
-level <-2..2>       指定初始显示的垂直层级
-follow              启动后直接进入运行页并跟随第一辆电车
-warp <秒>           启动前预先快进指定模拟秒数
-cam <x,y,zoom>      指定初始相机坐标（米）与缩放倍率
-shot <path.png>     运行指定帧数（-frames）后保存截图并退出
```

## 项目结构

| 目录 | 说明 |
| :--- | :--- |
| `main.go` / `shot.go` | 程序入口、命令行参数解析与自动截图封装 |
| `city` | 确定性生成网格新城的地块、河流、桥梁、公园与多类型建筑用地 |
| `mapdata` / `cmd/osmimport` | 内嵌压缩的西雅图 OpenStreetMap 地图数据与 OSM XML 投影裁剪导入工具 |
| `street` | 路网与多层级轨道核心：街道、空地/高架/地下独立轨道、出入坡道、车道与路口几何、多相位信号灯、车站、渡线、31 款电车参数与编辑重放 |
| `traffic` | 固定步长确定性交通与客运模拟：IDM 跟车、路口冲突互斥、单线闭塞与逆行预留、车门状态机、方向性客流、实时限速/定员与全状态快照 |
| `build` / `rail/sim` | 独立轨道闭塞信号模拟核心与多层级建造规则 |
| `game` | Ebitengine 矢量渲染与交互界面：多级 LOD 车辆与立体设施绘制、视野裁剪、工具栏、线路管理、多槽位存档及旧版地图存档自动迁移 |
| `internal/locale` | 中英文双语词条切换与系统语言检测 |
| `internal/sound` | 电机、齿轮、路口铃声、车门音效实时合成器与系统语音报站调度 |
| `internal/textui` / `internal/platforminput` | 矢量字体排版渲染与 macOS 原生触控板双指捏合手势支持 |

地图数据说明：西雅图地图数据 © OpenStreetMap contributors，依 [ODbL](https://www.openstreetmap.org/copyright) 许可使用。
