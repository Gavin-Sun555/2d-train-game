# 2D Train Game

俯视角 2D 电车 / 轻轨 / 地铁模拟，**Go + [Ebitengine](https://ebitengine.org/)**。

## 玩法（v0.1：地面有轨电车）

在一座简单的网格城市上铺设地面电车轨道、设站、开线路，电车会自动往返运营。

| 键 | 工具 / 操作 |
| :--- | :--- |
| `1` 轨道 | 点击起点，再点击铺一段直线轨道，可连续铺；右键 / `Esc` 结束。吸附到半格网格（街道中线）和已有节点；与已有轨道交叉自动生成路口。预览绿色可建，红色并标出受阻位置。 |
| `2` 车站 | 点击轨道放置车站（不能放在路口上）。 |
| `3` 线路 | 依次点击车站，`Enter` 建线（一辆电车往返）；右键撤销上一个站，`Backspace` 删除最新线路。 |
| `4` 删除 | 点击删除一段轨道，孤立的车站与失效线路随之删除。 |
| `Tab` | 切换建造层级（高架 / 地下已预留，暂未开放）。 |
| `WASD` / 方向键 / 中键拖动、滚轮 | 平移、缩放 |
| `Space`、`+`/`-`、`B` | 暂停、倍速、显示闭塞占用 |

地面轨道可以建在道路、桥梁、空地和公园上，不能穿过建筑或水面。转角最大 90°（尚无曲线），线路不能在中途折返。

## 结构

| 目录 | 作用 |
| :--- | :--- |
| `city` | 城市地图：瓦片（道路、桥、水、公园、建筑），按种子确定性生成。 |
| `build` | 玩家建造模型：轨道段、车站、线路；按层级规则校验，编译成 `sim.Network`。 |
| `rail/sim` | 纯模拟核心，**禁止引用 ebiten**。固定步长 `DT = 1/60 s`，确定性执行，可 headless 测试与回放。 |
| `game` | Ebitengine 表现层：镜头、输入、工具、绘制。 |
| `main.go` / `shot.go` | 入口；`-demo` 示例线网，`-warp` 快进，`-shot` 截图。 |

## 为地铁与高架轻轨预留的设计

- **层级 `sim.Level`**：`Ground` / `Elevated` / `Underground`。节点和轨道都带层级，同层才会自动连接、生成路口；不同层的轨道交叉互不影响。将来用两端层级不同的"坡道 / 洞口"边连接各层。
- **层级规则 `build.Rules`**：每层可通行的地块不同（地面：道路 / 空地 / 公园 / 桥；高架：另可跨水；地下：任意），`Buildable` 控制是否开放。
- **运营模式 `build.Mode`**：`Tram` / `LightRail` / `Metro`，各自有所属层级和车辆参数（长度、速度、加减速）。

## 模拟模型

- **轨道网络**：节点 + 直线边；默认每条边是一个**闭塞分区**。
- **路口闭塞**：与同一路口（含平面交叉）相连的边合并成一个闭塞，同一时间只允许一辆车在路口区域内；编译时在路口两侧切出 20 m 的短区段，避免路口闭塞过长。
- **列车位置**：`trail`（从车尾到前方已占 / 已预留的边）+ `head`，不使用物理引擎。
- **闭塞信号**：按"制动距离 + 50 m"向前预留，被占用时停在红灯前；车尾驶出后释放。车站出站信号在停站结束前保持红灯。
- **寻路**：Dijkstra 按"边 + 方向"搜索，限制转角 ≤ 90°，禁止中途折返；终点站自动换端折返。
- **速度曲线**：`v = min(Vmax, √(2·d·s))`，车头精确停在站台点。

## 使用

```bash
make run              # 启动（空城市）
./traingame -demo     # 带示例线网启动
make test             # headless 测试（安全不变量每 tick 检查）
```

## 已知限制 / 下一步

- 转角是折线，没有曲线半径与限速；对向列车共用单线可能互相锁死。
- 编辑后电车会重置到起点；尚无撤销、存档、时刻表、乘客与经济。
- HUD 用调试字体，只能显示英文；中文需要接入字体（可复用 bus game 的 `textui`）。
